# DESI Two-Point Correlation Function (2PCF) Investigation

This investigation focuses on computing the two-point correlation function (2PCF) for GALFORM galaxies, with a specific focus on comparing with DESI observational data.

## Scientific Objectives

1.  **Galaxy Clustering:** Measure the clustering of galaxies in GALFORM simulations as a function of various properties (e.g., stellar mass, color).
2.  **Comparison with Observations:** Compare the simulated 2PCF results with observational constraints from the Dark Energy Spectroscopic Instrument (DESI).
3.  **Model Validation:** Use the comparison to validate the GALFORM semi-analytic model and understand how well it reproduces the observed large-scale structure of the Universe.
4.  **SCOPE Comparison:** Investigate how results from traditional 2PCF estimators compare with those from the SCOPE (Sub-volume Correlation Function Estimator) method, particularly for projected correlation functions ($w_p$).

## Notebooks

*   **`desi_2pcf.ipynb`**: Contains the core analysis for computing the 2PCF and comparing it with DESI data, as well as the comparison with the SCOPE method.
